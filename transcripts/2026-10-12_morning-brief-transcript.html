Home Lending

Host: In home lending, stay with FHA alternative credit scores, but narrow the operational point. HUD's October 8 FHA INFO says the real workflow is Minimum Decision Credit Score handling for Title II FHA case numbers assigned on or after January 1, 2027.

Co-host: We covered the policy yesterday. What is different today?

Host: Today's useful angle is implementation prep. HUD says mortgagees should work with credit and technology partners so systems, processes and capabilities are ready, and it points to TOTAL Scorecard Developer's Guide Release 5.0 for automated underwriting integration.

Co-host: Which loan file is affected?

Host: An FHA Title II file where multiple models, such as Classic FICO, FICO Score 10T and VantageScore 4.0, may be submitted. The lender has to know which score drives the transaction-level MDCS and how that score flows into TOTAL.

Co-host: What is the consequence if lenders are not ready?

Host: A borrower can get a quote or eligibility answer that later changes because the vendor output, automated underwriting setup or overlay did not match. For loan officers, the safe promise is not "FHA accepts new scores." It is the case-number date, the model used and the lender's actual implementation status.

Co-host: So this is a systems-readiness story, not a rate story.

Host: Correct. Watch for office-hours clarifications, the January TOTAL release, credit-vendor notices and lender overlays. That is where an access policy becomes a file-level process.

Co-host: Does this change underwriting discretion?

Host: Not by itself. It changes the data and model path that feeds the FHA decision. Underwriters still need complete borrower documentation, and lenders can still apply overlays. The implementation question is whether the file is evaluated consistently when newer score models enter the pipeline.

Co-host: That is a better borrower explanation than saying a new score model automatically opens credit. The possible benefit is real, but the first phase is making sure lenders do not create preventable confusion.
