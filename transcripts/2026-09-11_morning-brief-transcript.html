Home Lending

Host: In home lending, the operational change is not a rate quote. Fannie Mae's September ninth lender letter says VantageScore 4.0 is now broadly available to all Fannie Mae-approved lenders, effective immediately. Lenders may originate and deliver eligible loans using VantageScore 4.0 without prior written approval.

Co-host: What changes in the loan file, not just the policy headline?

Host: Credit ordering, automated underwriting, pricing, and delivery data all change. Fannie says Desktop Underwriter version 12.1 now permits credit reports using VantageScore 4.0 for all DU casefiles. If a lender chooses that model, it must request VantageScore 4.0 from each of the three repositories, use the same score model for all borrowers on the loan, retain the report in the file, and deliver Special Feature Code 067.

Host: There are important limits. Lenders that are not ready can keep using eligible Classic FICO models. Manual underwriting still uses Classic FICO. FICO Score 10T is not currently eligible for delivery. And Fannie says the Selling Guide will be updated later, so compliance teams still have a bridge period between the letter and full guide text.

Co-host: Why does this matter before a borrower ever hears the phrase VantageScore?

Host: Because the first risk is operational inconsistency. A lender cannot let one channel order Classic FICO, another order VantageScore, and pricing or delivery staff discover the mismatch late. The opportunity is broader credit access and potentially better fit for some thin-file borrowers. The control is making sure loan officers, credit vendors, underwriting systems, LLPA tables, disclosure checks, and delivery edits all know which score model drove the decision.

Co-host: It also changes training. A loan officer needs to know whether a different score model actually changed eligibility, or whether the file still failed because income, assets, collateral, debt ratio, or manual-underwriting rules did not move.

Host: Rate context stays brief: today's hotter CPI and higher oil tone may keep daily mortgage pricing tense even though VantageScore changes eligibility plumbing. Watch whether Freddie Mac posts matching operational detail, and whether lenders publish overlays before putting the new score model into ordinary production.
